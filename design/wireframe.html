Golden Window — Web Wireframe Walkthrough

A desktop-first website, not a phone port. The week and the timeline finally get room to breathe, and every point is clickable. Same design language as the iOS app: the six-tier comfort scale, the rare Golden celebration, blue for interaction / gold for brand, safety kept separate, and New York serif (ui-serif, Georgia, serif) for the score and verdict. Light & dark both follow the system; each panel is framed as a browser window. Sample data is a bright Brooklyn day for a sun-loving, humidity-averse profile — the Today timeline below is live: hover it, and click a point to pin an hour.

0 · Global chrome — the top bar & navigation

One persistent bar on every screen: brand wordmark, primary nav (Today / Week / Settings), the current location + freshness, a city/ZIP search, and a light/dark control. It stays sticky as you scroll a long Today page.

Layout logic: hero row is a fixed 390px score column + fluid timeline; the dashboard is a 6-column grid (right-now 2, metrics 4, breakdown 4, week-peek 2). The one custom component — the timeline — earns the widest cell. Everything else is standard cards.
A11YScore is number + word ("8.5 · Great"), never color alone; every metric pairs a value with an interpreted verdict word. Contrast holds AA in both themes. The dashboard reflows to one column under ~760px (see §7). Ring is decorative; the accessible name is the "8.5 out of 10, Great" text.

3 · The Week — seven across, big-screen

Where desktop pays off most. Seven day-cards in a row, each scannable at a glance: weekday, sky glyph, score badge in its band color, best window, hi/lo and a one-line "day character." A Golden day (9.0+) gets the full gold-gradient + sparkle treatment so it stands out from a merely-Great one. Hover lifts a card; clicking drills into that day.

First run teaches the app what "good weather" means to this person. Web-native two-column: the question and slider on the left, a live "for you" preview on the right that updates as you drag. Skippable to sensible defaults at any point.
